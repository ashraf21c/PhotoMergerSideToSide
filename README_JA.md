# 見開き風画像結合

`run_book_style_merger.bat` をダブルクリックしてアプリを起動します。
JPG、PNG、WebP 画像を1枚以上アップロードしてください。画像ごとに
トリミング、端の補正、個別編集を設定できます。

## 言語

起動時にブラウザーの優先言語を自動検出します。**言語**メニューから
英語・アラビア語・日本語を選べます。手動で選択すると、現在の
ブラウザーセッションでは自動検出より優先されます。アラビア語では
画面を右から左へ表示します。

## 曲がったページ端の補正

1. 画像の設定を開き、**曲がったページ端を補正**を有効にします。
2. 曲がっているページ端に合わせて**左**または**右**を選択します。
3. プレビューの赤線を確認します。画像上部・中央・下部の端の位置が
   自動推定されます。
4. 赤線がページ端に合わない場合、**上端の x 座標**、**中央の x 座標**、
   **下端の x 座標**を調整します。値は水平方向のピクセル座標です。
   `0` は画像の左端、最大値は右端です。座標はトリミング後の画像に
   対する値です。少しずつ変更し、赤線を確認してください。
5. **補正の強さ**を調整します。`0%` は元画像のまま、`100%` は補正を
   最大限適用し、中間値は元画像と補正結果を合成します。

この補正は選択したページ端をまっすぐにしますが、遠近感全体の自動
補正や、曲がった本文の完全な補正ではありません。自動検出がページ端
に合わない場合は、3点を手動で調整してください。

## 画像の順序とギャラリー

各画像に重複しない**画像の順序**番号を付けます。番号の小さい画像が
先に表示されます。1から画像数までの番号をそれぞれ1回ずつ使います。
**1行あたりの画像数**で各行の枚数を設定します。入りきらない画像は
次の行に配置されます。**右から左**では最小番号の画像が各行の右端に、
**左から右**では左端に配置されます。

## 画像ごとの編集

**この画像を個別に編集**を有効にすると、ギャラリーにまとめる前に
拡大率、明るさ、コントラスト、シャープネス、彩度を個別に調整できます。
必要に応じて画像の幅と高さも指定できます。ギャラリー全体にも追加の
仕上げを適用できます。

レイアウト設定で**画像のサイズを統一（トリミングなし）**を有効に
すると、各ページの境界を検出し、ページの見た目の大きさを統一します。
元の背景を含む写真全体を保持し、トリミングや拡大はしません。統一後の
写真全体が入るサイズの枠を作り、追加の余白はギャラリーの背景色で埋め
ます。ページを検出できない場合は警告を表示し、画像全体の範囲を使って
サイズを合わせます。

## ダウンロード形式

- **PNG** は JPEG 圧縮を行わず、ギャラリー全体のサイズを保ちます。
- **JPG** はギャラリー全体を高画質 JPEG として保存します。
- **Web 用に圧縮してダウンロード**は、品質 82% の JPEG を作成し、
  長辺を最大 2560 ピクセルに縮小します。

## アプリアイコン

`app_icon.png` は Streamlit ページのアイコンとして使われ、ブラウザー
のタブとページタイトルの横に表示されます。`app_icon.ico` は Windows
ショートカット用のアイコンです。Streamlit アプリはブラウザー内で
動作するため、通常のブラウザーウィンドウではブラウザー自身が
ウィンドウやタスクバーのアイコンを管理します。Web ページからそれら
のネイティブアイコンを変更することはできません。

## UI に言語を追加する

1. `localization.py` を開きます。
2. `LANGUAGES` に言語コードとその言語での名称を追加します。例:
   `"fr": "Français"`。
3. `TRANSLATIONS` に `"fr"` の項目を追加し、アプリで使われる英語の
   各ソース文字列を翻訳します。`{width}` や `{filename}` のような
   `{}` 内のプレースホルダーは、書式付きメッセージが動作するよう
   変更しないでください。
4. ブラウザーの言語を自動検出するには、`BookStyleImageMerger.py` の
   `detect_language` 関数にも言語コードを追加します。追加しなくても
   メニューから手動で選択できます。
5. 必要に応じて README の翻訳も追加し、アプリを再起動してコントロール、
   エラーメッセージ、書式付き説明を確認します。

翻訳がない文字列は英語で表示されます。
